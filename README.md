# Responsive Portfolio Website (HTML & CSS)

A beginner-friendly portfolio website built with only HTML and CSS. No frameworks, no libraries.

![Preview](preview.png)

**Live demo:** https://YOUR_USERNAME.github.io/portfolio-website-html-css/
**Video tutorial:** YOUR_YOUTUBE_VIDEO_LINK

## What's inside
- Sticky navbar with Flexbox
- Typing animation and glowing button (pure CSS)
- Project cards with CSS Grid and hover effects
- Styled contact form
- Fully responsive with media queries
- CSS variables for easy re-theming

## Folder structure
| Path | What it is |
|------|-----------|
| `index.html`, `style.css` | The finished project |
| `starter/` | Blank template to follow along with the video |

## How to use
1. Click **Code > Download ZIP** (or `git clone` this repo).
2. Open the folder in VS Code and run **Live Server** on `index.html`.
3. To follow along, open the `starter/` folder instead and code with the video.

## Make it yours
Change the colors by editing the variables at the top of `style.css`:
```css
:root {
  --accent: #22d3ee; /* try hotpink */
}
```
